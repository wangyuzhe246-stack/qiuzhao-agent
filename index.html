技术架构

本地服务 + 网页工作台，数据只在本地，不上传第三方

🔧 技术栈

  • 后端：Node.js + Express，绑定 127.0.0.1
  • AI：DeepSeek Responses API（deepseek-v4-flash），内置 web_search 联网搜索
  • 前端：原生 HTML/CSS/JS 单页工作台，无构建步骤
  • 存储：本地 JSON 文件（数据/岗位/材料/设置）
  • 投递：每岗定制简历(.doc)下载 + 逐站投递指引，提交由用户手动完成

⚙️ 模块划分

  • llm.js — DeepSeek 封装（联网找岗/定制材料/稳定解析 JSON）
  • jobSearch.js — 多轮搜索 → 打分 → 模糊去重 → 入库（核心）
  • tailoring.js — 按 JD 生成定制简历/自我评价/网申答案
  • store.js — JSON 文件读写；routes.js — REST 接口

我做了什么（项目亮点）

💡 关键设计

  • 11 轮定向联网搜索，优先 30 个官方/招聘平台，返回真实投递入口
  • 0-100 匹配打分：公司类型 40 + 关键词 30 + 学历 10 + 城市 20
  • 福利抽取与评级：识别薪资/双休/险种/补贴，按规则评 优/良/中/差
  • 模糊去重：规范化公司名 + 岗位词重叠判断，63 个近似岗位合并到 41 个不重不漏
  • LLM 输出不稳定时自动回退重试，保证 JSON 解析成功率

📈 结果

  • 真实运行：整理出 41 个有效岗位，覆盖字节跳动、岚图汽车、中建八局文旅等
  • 20 个岗位福利达「优」（五险一金 + 双休 + 补贴齐全）
  • 央国企 / 大厂岗位占比 ≈ 83%，符合「央国企优先，其次大厂」的偏好
  • 全部数据本地存储，AI 只在本地账号下调用，隐私可控
